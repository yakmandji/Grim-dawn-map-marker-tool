Grim Dawn

Custom marker tool

Grim Dawn Custom Marker Tool is an interactive map that lets you create custom markers, plan routes, and explore Cairn, Malmouth, and the Korvan Basin. Includes multi-language support, import/export, and advanced map navigation.

Privacy

Grim Dawn Custom Marker Tool does not collect, track, or store any personal data.

This tool works without user accounts. All markers, routes, notes, and progress are stored locally in your browser using local storage.

When you choose to share a map, only the necessary map data (such as marker coordinates, routes, and related metadata) is stored on the server to generate a shareable link. No personal information is included or associated with shared data.

No analytics, cookies, or third-party tracking services are used.

This project is open-source and can be audited on GitHub
